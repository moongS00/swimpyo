## 5. Stage 3 합성에서 검증할 수렴 방향

위 드라이버에서 자연스럽게 도출되는 아키텍처 후보 방향:

> **단일 Streamlit 앱 + 사전 계산된 모델·데이터 산출물(파일) + 외부 LLM API 호출 + 호출 직전 비식별화 게이트**

Stage 3에서 이 후보를 다른 대안과 ATAM 방식으로 비교 평가하여 확정한다.

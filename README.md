# 쉼표(Swimpyo)

**AI 기반 교사 업무·감정 부담 조기경보 및 맞춤 지원 연결 시스템**

> 제8회 교육 공공데이터 AI 활용대회 출품작

---

## 대회 소개

**제8회 교육 공공데이터 AI 활용대회**는 교육 분야 공공데이터를 AI 기술과 결합하여 교육 현장의 실질적인 문제를 해결하는 서비스를 기획·구현하는 대회입니다.

---

## 프로젝트 개요

### 문제 인식

교사 번아웃과 정신건강 위기가 사회적 이슈로 부상했지만, 현재 교사 지원 체계는 **사후 대응**(휴직 신청 후 상담 연결)에 머물러 있습니다. "어떤 학교의 어떤 조건에서 교사가 위험 상태에 놓이는가"에 대한 **데이터 기반 예측 체계는 전무**한 상황입니다.

### 해결 방안

교육 공공데이터(학교알리미, 교육통계서비스 등)를 활용하여 학교 단위의 **구조적 위험 요인**을 분석하고, 교사 번아웃 발생 가능성이 높은 환경을 **선제적으로 예측**하는 AI 시스템을 구축합니다.

---

## 주요 기능

### A. 관리자 대시보드 (교육청·지원센터용)
- **전국 위험 지도** — 시도·시군구별 학교 위험도 히트맵 (녹색/황색/적색)
- **학교별 TBRI 리포트** — 교사 업무부담 위험 지수(TBRI) 상세 분석 및 SHAP 기반 위험 요인 시각화
- **What-if 시뮬레이터** — 조건 변경 시 위험도 변화를 실시간 예측 (예: "기간제 교사 2명 추가 배치 시 효과")
- **지원 자원 매칭** — 위험 요인별 맞춤 지원 프로그램 자동 추천

### B. 교사 셀프체크 웹앱 (교사 개인용)
- **간편 입력** — 학교 조건 5개 항목 입력 (30초 소요)
- **위험도 확인** — TBRI 점수 및 주요 위험 요인 설명
- **맞춤 지원 안내** — 지원 프로그램·교원치유지원센터 정보 제공
- **익명 상담 연결** — 로그인 없이 이용, 개인정보 수집 없음

## 활용 데이터

| 데이터셋 | 출처 |
|---------|------|
| 교원 현황 (정원 대비 현원, 기간제 교사 비율) | 학교알리미 / 교육통계서비스 |
| 교사 1인당 학생 수 · 학급당 학생 수 | 학교알리미 |
| 교원 휴직 현황 (질병·육아·기타 사유별) | 교육통계연보 / 공공데이터포털 |
| 학교폭력 실태조사 결과 | 학교알리미 |
| 학교 행정업무 현황 | 학교알리미 공시항목 |
